# Generated / reference token stubs

**Version:** v1.0.0-beta.3 (Build 4)

These files mirror `../tokens.json` for copy-paste into native targets. They are **not** compiled by Warpbeat MAUI.

| File | Use |
|------|-----|
| `RZTokens.swift` | iOS / SwiftUI constants |
| `RZTokens.kt` | Android / Compose constants |
| `../tokens.css` | Web (authoritative CSS export) |

When `tokens.json` changes, update these stubs (or replace with a generator later).
