# ReZephyr simulated previews

**Version:** v1.0.0-beta.3 (Build 4)

Open locally:

```bash
# Windows
start previews/index.html

# macOS
open previews/index.html
```

Or serve the repo root so relative token/brand paths resolve:

```bash
npx --yes serve .
# then open /previews/
```

| Preview | What you see |
|---------|----------------|
| **Web** | Desktop card surface using `tokens.css` |
| **Apple** | 390×844 phone frame — large title, acrylic dock, sheet |

Toggle **Both / Web / Apple** and **Light / Dark** in the header.
