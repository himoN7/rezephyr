# ReZephyr.Tokens

**Version:** v1.0.0-beta.3 (Build 4)

NuGet content package with ReZephyr token sources for **Swift / Kotlin / Flutter / CSS / JSON**.

For runnable .NET UI packages use **`ReZephyr.Maui`** or **`ReZephyr.Avalonia`**.

Native packages:
- Swift SPM — root `Package.swift`
- Android — `com.himpire.rezephyr:rezephyr-compose`
- Flutter — git path `platforms/flutter/rezephyr`
